# ManishaMart

Multi-seller e-commerce marketplace 

## Problem Statement

Sellers list products. Buyers browse, search, add to cart, and purchase. An admin
manages users, orders, and listings. Built with Java Servlets, JDBC, and Apache Tomcat.

## Tech Stack

| Component | Technology |
|---|---|
| Language | Java 17 |
| Servlet container | Apache Tomcat 9.0.x |
| Build tool | Maven |
| Database | H2 (embedded for dev, server mode for deployment) |
| Connection pooling | HikariCP |
| Password hashing | jBCrypt |
| JSON serialization | Gson |
| View layer | Vanilla JS + fetch() for AJAX endpoints |
